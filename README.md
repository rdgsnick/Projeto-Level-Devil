# Projeto-Level-Devil

Jogo de plataforma estilo Level Devil, feito só com HTML, CSS e JavaScript.

- **Jogar:** abra `jogo/index.html` no navegador (ou use o Live Server do VS Code).
- **Entender o código:** leia `jogo/LEIA-ME.txt` (como tudo está organizado e como criar fases, armadilhas e inimigos).
- **O que mudou nesta versão:** leia `MUDANCAS.md`.
- A fase só começa quando o gato se mexer (anda, pula, dash, agacha ou ataca).

Controles: setas/AD andar · espaço pular · Shift agachar · Q dash · clique esquerdo espada (W/S + clique = cima/baixo) · R reiniciar fase.
